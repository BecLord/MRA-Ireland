# MRA Ireland

A static website redesign for the Motorcycle Racing Association of Ireland (MRA) a project for my Client-Side Web Development module from Year 3, Semester 1.

The site provides an introduction to MRA, its off-road motorcycle disciplines, events, championships, competitors, clubs and news.

## Pages

- `home.html` - main landing page
- `events.html` - race calendar and event information
- `championships.html` - championship information
- `competitors.html` - competitor hub and licence guidance
- `clubs.html` - affiliated club information
- `news.html` - MRA news
- `resources/` - rule book, policies, coaching and other competitor resources

## Technologies

- HTML5
- CSS3
- Static images
